# Namaz & Dua Tracker (Android)

Offline app for Asharaf Ghayas, Amreen Fathima and Arshad Ghous. Works on Android 8.0 – 16.

## Get the APK (no installs needed) — GitHub
1. Create a free GitHub repository and upload everything in this folder (keep the `.github` folder).
2. Open the **Actions** tab → **Build APK** → wait ~3 minutes.
3. Open the finished run → download **NamazDuaTracker-apk** (a zip) → unzip → `app-debug.apk`.

## Or with Android Studio
Open this folder → **Build ▸ Build Bundle(s)/APK(s) ▸ Build APK(s)**.
Output: `app/build/outputs/apk/debug/app-debug.apk`

## Install
Send the APK to each phone (WhatsApp/Drive/USB), tap it, allow "Install unknown apps" when asked.

## Editing tasks
All task text, counts and day-limits live in `app/src/main/assets/index.html` (`DATA` array).
